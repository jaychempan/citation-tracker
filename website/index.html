三步开始

安装

添加 Scholar 主页后，即可开始自动追踪被引变化。

  1. 从 Chrome 应用商店安装扩展
  2. 点击工具栏图标，输入你的 Google Scholar 用户 ID
  3. 首次刷新保存论文初始记录，之后自动记录被引增长

从 Scholar 主页 URL 中获取你的 ID：

scholar.google.com/citations?user=DhtAFkwAAAAJ&hl=en

v1.5.0 安装包可用于开发者模式安装。Chrome 应用商店当前为 v1.4.0，新版需另行提交商店审核。

开发者模式安装

  1. 下载 v1.5.0 安装包并解压
  2. 打开 Chrome，地址栏输入 chrome://extensions
  3. 开启右上角「开发者模式」开关
  4. 点击「加载已解压的扩展程序」，选择解压后包含 manifest.json 的目录
  5. 安装完成，工具栏出现 Citation Tracker 图标

已有开发者模式安装：替换扩展目录中的文件，然后在 chrome://extensions 点击重新加载。学者数据和偏好会保留。

FAQ

常见问题

它会读取我的 Google 账号吗？

不会。扩展仅请求公开的 Google Scholar 被引数据，不读取账号信息、邮件或浏览历史。

为什么第一次刷新没有显示被引增长？

第一次刷新用于保存论文初始记录。从第二次成功刷新开始，扩展才会比较并记录被引增长。

可以追踪多位研究者吗？

可以。你可以添加多个 Scholar 用户 ID，并按学者筛选论文与被引动态。

数据可以导出吗？

当前版本专注于本地追踪和浏览，暂未提供导出功能。你可以在 GitHub 提交功能建议。

如何切换语言和主题？

点击弹窗顶部的「中文 / EN」切换语言，在底部的主题菜单选择「松绿」或「石墨」。选择会自动保存。
